# República del Verde

Página de pedidos para República del Verde (bolones, tigrillos y empanadas de verde). Negocio solo online, con entrega a domicilio. El cliente arma el pedido, pone su dirección y se le abre WhatsApp con el mensaje listo.

- `index.html`: página final, un solo archivo. Se puede abrir directo o subir a cualquier hosting.
- `src/page.html`: código fuente con marcadores `%%...%%`.
- `assets/`: tipografías, logo e íconos.
- `build.py`: vuelve a armar `index.html` con `python3 build.py`.

## Datos a cambiar (en `src/page.html`)
- Número de WhatsApp de pedidos: `0968375755` (enlaces `wa.me/593968375755`).
- Horario: 07:30 a 12:30.
- Menú y precios: atributos `data-item` de cada plato.

- Días de atención.
- Fotos de los platos.
